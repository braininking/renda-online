# Radar de Oportunidades

Operação separada do OfertaBot para gerar tráfego e monetização por recomendações, conteúdo e serviços.

## Estrutura
- index.html: página pública
- offers.json: catálogo de ofertas
- config.json: configuração da operação
- gerar-conteudo.ps1: rotina local para preparar conteúdo
- relatorio.ps1: relatório simples de cliques/arquivos

## Monetização
O projeto está preparado para usar links próprios de afiliado. Não foram inventados links de terceiros.

Amazon: a identificação de associado configurada é ofertaradar03-20.
Shopee, Mercado Livre e Magalu ficam habilitados na estrutura, mas os links precisam ser os links personalizados gerados nas respectivas contas.

A Amazon exige identificação clara de que o site recebe comissão por compras qualificadas. A página pública já contém essa informação.

## Importante
A publicação automática em plataformas externas e a ativação de contas de pagamento/afiliado dependem de autenticação e aprovação do proprietário. O projeto não tenta burlar essas etapas.
